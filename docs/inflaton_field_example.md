# The inflaton field example

In the following section, we describe how to run the inflaton field example. This example implements the classical stochastic initial conditions used in lattice cosmology simulations of inflation. 

_As this example relies on the use of a Fast Fourier Transform (FFT), the user must be particularly careful about their use of AMR when running this example_
